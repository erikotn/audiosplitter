# AudioSplitter

Knip een lang audiobestand in chunks van een vaste lengte. Lokaal in je browser — niks gaat de server op.

**👉 [Open de tool](https://audiosplitter-seven.vercel.app)**

## Wat het doet

- Upload een audiobestand (mp3, wav, m4a, etc.)
- Stel chunk-lengte in (bijv. elke 10 minuten)
- Download alle stukjes als losse bestanden
- Werkt 100% client-side via de Web Audio API — je file blijft op je eigen machine

## Voor wie

Podcast-makers, transcribers en mensen die een lang interview moeten opdelen voor uploadlimieten van transcript-tools.
